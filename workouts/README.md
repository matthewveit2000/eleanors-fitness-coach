# Workouts Directory

This directory stores monthly workout session logs for Eleanor (e.g. `2026-08.md`, `2026-09.md`).

## Format Guidelines

Each month file follows this structure:

```markdown
# Workouts — Month YYYY

## YYYY-MM-DD — <Session Type / Day Name>
- Exercise: sets x reps @ weight (mention RIR/how it felt if available)
- Exercise: sets x reps @ weight
- Notes: session duration, RIR, energy, gym notes
```

## Conventions
- Heading format: `## YYYY-MM-DD — <Session Type>` (e.g. `Day 1 — Full Body A`, `Zone 2 Run`).
- Default RIR is 0 unless stated otherwise.
- Failed reps use completed reps ($N-1$) for Epley e1RM calculations.
- Big jumps on machines across different gyms are flagged per the Gym-Comparability Rule in `AGENTS.md` and `PROGRESS.md`.
