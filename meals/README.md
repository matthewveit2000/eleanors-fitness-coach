# Meals Directory

This directory stores monthly meal logs for Eleanor (e.g. `2026-08.md`, `2026-09.md`).

## Format Guidelines

Each month file follows this structure:

```markdown
# Meals — Month YYYY

Targets: ~XXXX kcal · ~XXXg protein · ~XXg fat · ~XXXg carbs (see NUTRITION.md)

## YYYY-MM-DD
- Meal/Item: description — XXX kcal, XXg protein, XXg fat, XXg carbs (source tag)
- Another item: description — XXX kcal, XXg protein, XXg fat, XXg carbs (source tag)
- **Daily total so far: ~XXXX kcal, ~XXXg protein, ~XXg fat, ~XXXg carbs** (vs. target)
```

## Source Tags
- `(exact, from label)`: Directly from packaging
- `(official <brand> nutrition info, exact)`: From manufacturer/restaurant official data
- `(estimate — <one-line reasoning>)`: USDA standard or visual portion estimate

## Multi-Item Rule
Always log items individually line-by-line with their respective macros, never blended into a single unitemized total.
